Use this package to easily transition between scenes using a custom fade and/or scale animation.

How to use:
- Place the SceneTransitionManager prefab in all your scenes.
- Add a status text or loading bar if you wish (not required).
- Set the Animation Settings to something you like. Note, curves that are mirrored give the best results!
- You can put the SceneTransition script on a button or something else that can't directly call the manager.
